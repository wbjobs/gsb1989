# Canvas 力导向关系图

零依赖原生实现的力导向关系图，支持拖拽、聚类、持久化和异常降级。

## 运行

```bash
npm start
# http://localhost:5173
```

运行测试：

```bash
npm test
```

性能基准：

```bash
node scripts/benchmark.js 1000
node scripts/benchmark.js 3000
```

## 技术实现

- `Canvas 2D`：批量绘制边、节点、凸包聚类区域；限制 DPR，静态时使用脏渲染避免空转。
- `Web Worker`：力学仿真和 Louvain 聚类在后台执行，位置数据通过 `Transferable ArrayBuffer` 回传。
- `IndexedDB`：保存当前图和稳定布局快照；数据库不可用或超时时自动降级为内存存储。
- `Barnes-Hut 四叉树`：将节点斥力降为近似 O(n log n)。
- `空间哈希碰撞`：线性处理邻近节点碰撞，避免每帧再构建第二棵空间树。
- `加权 Louvain`：按边权重计算模块度增益；初始化兼容预设聚类，手动“重新聚类”会重新检测。
- `凸包渲染`：每个聚类生成扩展凸包，两点和单点使用胶囊/圆形区域兜底。

## 交互

- 拖拽节点：点击节点后固定并局部升温，主线程先即时更新坐标，Worker 持续计算邻接布局，释放后冷却。
- 拖拽画布：空白区域平移。
- 滚轮：以鼠标位置为中心缩放。
- 重新生成：生成 300、1000 或 3000 节点图。
- 重新布局：保持拓扑和聚类重新升温。
- 重新聚类：忽略预设标签，按当前边权重重新运行 Louvain。

## 异常降级

- Worker 创建或初始化失败：自动切换到主线程仿真，并在状态栏提示。
- IndexedDB 缺失、阻塞或操作超时：使用进程内 Map，刷新后不保留数据。
- Canvas 2D 不可用：显示明确错误，不静默空白。
- 非法节点、重复边、自环、缺失端点：清洗数据并输出警告，不中断布局。
- 空图或孤立点：生成独立社区，仿真保持稳定。

## 验收对应

- 布局稳定：Alpha 冷却到阈值以下且所有节点速度低于阈值后停止仿真。
- 拖拽流畅：拖拽期间 Worker 升温，本地立即更新节点，释放后自然冷却。
- 聚类正确：加权 Louvain 检测稠密子图，凸包按社区着色；单元测试覆盖双簇场景。
- 性能可接受：3000 节点、约 2.25 万边时，当前环境基准约 48ms 初始化聚类、约 7.2ms/次仿真，计算位于 Worker。
- 异常有降级：Worker、IndexedDB、Canvas 和脏数据均有兜底路径或可见提示。
